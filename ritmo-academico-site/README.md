# Ritmo Acadêmico

Site de 5 páginas (HTML, CSS e JavaScript) para organizar prazos de provas, trabalhos e leituras. Projeto de Desenvolvimento de Interfaces, ADS/CEUB (entrega E3).

## Para quem
Estudantes que precisam saber, de relance, qual é o próximo prazo e por onde começar.

## Como rodar
Não precisa instalar nada: extraia o `.zip` e abra `index.html` no navegador. As tarefas ficam salvas no próprio navegador (`localStorage`). A página `sobre.html` carrega o Tailwind por CDN, então precisa de internet para esse cartão aparecer estilizado.

## O que cada arquivo faz
| Arquivo | Função |
|---|---|
| `index.html` | Hoje: próximo prazo em destaque e lista do que vem depois |
| `agenda.html` | Todas as tarefas pendentes, com filtro por tipo e ordenação |
| `nova-tarefa.html` | Formulário de cadastro com validação |
| `tarefa.html` | Detalhe: concluir ou excluir (com confirmação) |
| `sobre.html` | O que é o app, para quem, e o cartão da equipe em Tailwind |
| `assets/css/style.css` | Todo o visual (variáveis, Flexbox, Grid, responsivo, tema escuro) |
| `assets/js/script.js` | Comportamento de todas as páginas |
| `assets/img/logo.svg` | Logotipo |
| `MUDANCAS.md` | O que difere do protótipo da E2 e por quê |
